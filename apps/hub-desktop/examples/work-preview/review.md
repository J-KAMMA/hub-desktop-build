# Review a small local change

- Read the requirements and the existing tests before proposing changes.
- Preserve all files except the requested implementation file.
- Check values whose type or representation can differ from their truth value.
- Request a test only after the final approved edit, and report its actual result.
- A successful test here covers this exercise only. It does not prove a whole repository or release is ready.

These instructions do not grant additional tools, permissions or approval.

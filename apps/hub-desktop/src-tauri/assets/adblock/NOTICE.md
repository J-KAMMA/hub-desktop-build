The lists are bundled snapshots. Updating this app can update the lists; opening a page does not download a filter list or send browsing data to the list provider.
YouTube page protection uses the pinned uAssets and uBlock Origin resources retained in youtube/. See youtube/ATTRIBUTION.txt, original source, GPL licenses and youtube-manifest.json. These page resources are separate from the unchanged network engine. Only exact HTTPS YouTube hosts receive them, with upstream MAIN/ISOLATED worlds preserved. Changing protection requires reloading an already opened YouTube page. Response-body $replace filters and alternate HTML filtering paths are not supported by this integration; it does not claim complete uBlock Origin equivalence.
